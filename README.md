
# CLI in .NET

A command-line tool for bundling source code files into a single file, with options for language filtering, file sorting, removing empty lines, and adding source information. The project also supports generating a response file for reusing commands.

## Features
- Select programming languages or include all supported source code types.
- Sort files by name or code type.
- Include source file names and relative paths.
- Remove empty lines.
- Add an author name.
- Generate a response file for reusable commands.

## Technologies
- C#
- .NET 8
- System.CommandLine
